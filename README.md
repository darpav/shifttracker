ShiftTracker Demo aplikacija za praćenje i razvrstavanje radnih sati

Opis aplikacije: Ovo je timska aplikacija izrađena na HealthIT akademiji. Jednostavna web aplikacija za praćenje i razvrstavanje radnih sati prema različitim vrstama rada. Aplikacija omogućava korisnicima unos radnog vremena prema rasporedu i automatski se razvrstavaju prema vrsti rada, pohranjuju i prikazuju u tablici

Glavne funkcionalnosti:

Unos radnih sati: Korisnici mogu unijeti broj odrađenih sati prema rasporedu. Razvrstavanje po vrstama rada: Radni sati se automatski organiziraju prema različitim kategorijama rada.
