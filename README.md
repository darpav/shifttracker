ShiftTracker 
Demo aplikacija za praćenje i razvrstavanje radnih sati

Opis aplikacije: 
ShiftTracker je jednostavna web aplikacija za praćenje i razvrstavanje radnih sati prema različitim vrstama rada. 
Aplikacija omogućava korisnicima unos radnih sati prema rasporedu i automatski se razvrstavaju prema vrsti rada, pohranjuju i prikazuju u tablici 

Glavne funkcionalnosti:

    Unos radnih sati: Korisnici mogu unijeti broj odrađenih sati prema rasporedu.

    Razvrstavanje po vrstama rada: Radni sati se automatski organiziraju prema različitim kategorijama rada.
